# CDSP Final Project

This project predicts hospital Length of Stay (LOS) using a trained CatBoost regression model and provides an interactive Streamlit interface for entering patient information and viewing the predicted number of days.

## Project Contents

- `app.py`: Streamlit application for LOS prediction.
- `Catboost_Model_LOS.pkl`: Trained CatBoost model used by the app.
- `CDSP_final.ipynb`: Notebook used for analysis, preprocessing, and model development.
- `LengthOfStay.csv`: Source dataset.
- `Cleaned_df.csv`: Cleaned dataset used during the project workflow.
- `catboost_info/`: Training artifacts generated by CatBoost.

## Features

- Predicts hospital stay length in days.
- Classifies predictions into stay categories such as short, moderate, extended, and prolonged stay.
- Displays relevant risk factors based on user inputs.
- Uses a cached model loader for faster repeated app runs.

## Requirements

Install the Python packages used by the project:

```bash
pip install streamlit pandas numpy catboost joblib
```

## How to Run

1. Open a terminal in the project folder.
2. Install the required dependencies.
3. Start the Streamlit app:

```bash
streamlit run app.py
```

4. Open the local URL shown in the terminal, usually `http://localhost:8501`.

## Notes

- The app expects `Catboost_Model_LOS.pkl` to be present in the same directory as `app.py`.
- If CatBoost loading fails, the app attempts fallback loading through `joblib` and `pickle`.
- The notebook can be used to review the data science workflow behind the final model.

## Disclaimer

This project is intended for academic and demonstration purposes. Predictions should not be used as a substitute for clinical judgment or medical decision-making.
